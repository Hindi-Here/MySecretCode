## Шифратор-Дешифратор вымышленного алфавита

**Функции**:
- создание алфавита с нуля;
- добавление/удаление символов алфавита;
- быстрое редактирование любого значения алфавита (важно соблюдать синтаксис "X = Y").
- шифратор/дешифратор созданного алфавита.

**Ограничение:** замена работает только с одиночными символами, чувствителен к регистру.
